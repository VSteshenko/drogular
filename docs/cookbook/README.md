# Cookbook

The Cookbook contains practical guides for solving common development tasks with Drogular.

Each guide starts with a specific problem and shows the recommended solution using the current Drogular implementation and working examples from the repository.

Use these guides after learning the framework fundamentals in Getting Started.

---

# Available Guides

## [Forms & Validation](forms-and-validation.md)

**Need to validate user input?**

Build reusable validation workflows with Drogular's forms and validation infrastructure.

---

## [State Management](state-management.md)

**Need to share state between pages or components?**

Organize shared application state around stores and predictable updates.

---

## [GraphQL](graphql.md)

**Need to communicate with a GraphQL server?**

Organize queries, mutations and application actions using Drogular's GraphQL support.

---

## [Localization](localization.md)

**Need to support multiple languages?**

Separate user-visible text from application logic through `TranslationProvider` and `RenderContext`.

# Reading Order

The Cookbook is organized by task rather than as a sequential tutorial.
