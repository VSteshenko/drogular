# Cookbook

The Cookbook explains the architectural patterns used throughout Drogular.

Unlike the Getting Started guide, these articles focus on engineering decisions and 
recommended practices rather than introducing individual framework features.

Every example is based on the current Drogular implementation and the accompanying examples. The Cookbook documents existing solutions rather than future APIs.
