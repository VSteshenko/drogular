# Cookbook

The Cookbook contains practical guides for solving common development tasks with Drogular.

Each guide starts with a specific problem and shows the recommended solution using the current Drogular implementation and working examples from the repository.

Use these guides after learning the framework fundamentals in Getting Started.

---

# Available Guides

## [Forms & Validation](forms-and-validation.md)

**Need to validate user input?**

Build reusable validation workflows with Drogular's forms and validation infrastructure.

---

## [State Management](state-management.md)

**Need to share state between pages or components?**

Organize shared application state around stores and predictable updates.

---

## [GraphQL](graphql.md)

**Need to communicate with a GraphQL server?**

Organize queries, mutations and application actions using Drogular's GraphQL support.

---

## [Localization](localization.md)

**Need to support multiple languages?**

Separate user-visible text from application logic through `TranslationProvider` and `RenderContext`.

---

## [Pagination](pagination.md)

**Need to display large collections of data?**

Parse stable request parameters, paginate application results, and preserve active filters while navigating between pages.

---

## [Server-driven Interactions](server-driven-interactions.md)

**Need to refresh server-rendered HTML without building a client application?**

Use Drogular Interactions for declarative fragment requests, polling, request state, connection state, and retry/offline 
behavior while keeping rendering on the server.

---

## [Authentication & Authorization](authentication/overview.md)

**Need to authenticate users and protect application resources?**

Establish application identity, manage sessions, protect Pages and Actions, enforce roles, and integrate custom 
authentication backends.

Related guides cover login/logout, session management, protected Pages and Actions, role-based authorization, security 
practices, and custom backends.

---

# Reading Order

The Cookbook is organized by task rather than as a sequential tutorial.

Open the guide that matches the problem you need to solve. If you are new to Drogular, begin with the [Getting Started guide](../getting-started/README.md).
