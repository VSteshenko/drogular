# ValidationError

**Namespace:** `drogular`  
**Header:** `<drogular/validation_result.hpp>`  
**Kind:** Struct

## Purpose

`ValidationError` represents one validation failure associated with one form field.

---

## Synopsis

```cpp
struct ValidationError {
    std::string field;
    std::string message;
};
```

---

## Members

### `field`

```cpp
std::string field;
```

The form field name associated with the error.

Field matching in `ValidationResult::hasError()` and `ValidationResult::error()` is exact and case-sensitive.

### `message`

```cpp
std::string message;
```

The human-readable validation message.

Messages generated by `FormValidator` are English strings. Applications that require localized validation messages should map or replace them at the application boundary.

---

## Example

```cpp
for (const drogular::ValidationError& error
     : validation.errors()) {
    std::cout
        << error.field
        << ": "
        << error.message
        << '\n';
}
```
